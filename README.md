# 周末出逃 · 城市探索指南

公开访问：https://huster-zc.github.io/meituan/

原生 HTML/CSS/JavaScript，无构建和服务端依赖，沿用 GitHub Pages 同域名部署。

## 已接入的真实数据

### 天气：Open-Meteo 免费非商业 API
- 固定武汉市中心经纬度 30.5928, 114.3055，不索取用户定位；无需 Key。
- 获取未来 14 天每日温度、WMO 天气代码、最大降水概率，时区 Asia/Shanghai。
- 周六/周日可选，周日只展示当天，避免推荐已过去的周六。
- 按所选日期自动筛选：WMO 代码 >=45（雾、雨、雪、雷暴）或降水概率 >=50% 时，只推荐室内。用户可手动选择仅室内或不限制，预报更新不会覆盖偏好。
- 30 分钟内复用缓存；请求超时 8 秒。失败可使用不足 24 小时且覆盖当前周末的旧缓存，并明确标注。没有有效缓存时不显示虚构温度、不按天气排除户外。
- 可手动重试。显示获取时间、缓存状态与来源署名；获取时间不是气象模型发布时间。
- 官方文档：https://open-meteo.com/en/docs
- 免费额度及用途：https://open-meteo.com/en/pricing （非商业；无可用性保证）
- 数据许可 CC BY 4.0，页面提供 Open-Meteo 来源链接。

### 活动：官方信息精选库
这部分是人工整理的带来源数据，**没有接入实时活动票务 API**。每条可推荐内容包含来源链接、发布日期、核对日期；限时内容带起止日期/开放星期，过期后从发现页隐藏。

当前内容：东湖绿道、昙华林、汉口江滩、光谷图书馆、武汉博物馆周末夜游、2026 长江文化艺术季。后者是活动季线索，必须查看具体武汉场次，不能视为已订票的单场演出。

已核实湖北美术馆 2026-08-13 起维护闭馆，暂停推荐。旧版虚构 Livehouse 与未指定书店的条目下架，但保留原 ID 供已有个人计划和手账读取，避免错配数据。后续恢复开放需根据新公告手动更新。

活动预算/路线/时长是产品建议；价格不含交通。来源中的免费信息不包含额外服务，图片均为氛围配图。较早的常设场所介绍不构成当前营业保证，预约与临时关闭以官方为准。

## 时间约束行程规划

“我的计划”可设置日期、首站到达、结束时间、交通方式（智能 / 步行 / 骑行 / 公交 / 汽车），每站停留和当天已核实的开放时段。智能模式按估算路程 ≤ 1 km 选择用户偏好的步行或骑行，较远路段使用公交。每段可手动修改交通与分钟数。切换日期或全程交通策略会清空逐段覆盖，防止误用旧估算；单站确认的营业时间仅适用于该日。

`planner.js` 在最多 7 站的范围搜索顺序及候选开始时间，优先安排更多地点，再减少偏离推荐时段、交通时间与结束时间；不声称导航意义上的最优路线。营业时间、停止入馆和完整停留是硬限制，推荐时段是软偏好，排不进去的地点保留并解释。允许手动顺序。暂无跨天、多时段自定义表单、实时路况、跨江道路识别、预约库存或多人同步。

地点中心来自 OpenStreetMap（ODbL，页面有来源链接）。路程用球面直线距离 × 1.35 估算；速度为步行4.5、骑行12、公交22、汽车28 km/h，骑行/公交/汽车分别加5/18/10分钟余量并向上取5分钟。它不是道路导航或实时公交数据。启用出发与返程后，首尾路段必须填写耗时才会排程。户外游玩范围明确标注为建议，未知场馆营业时间须先确认。武汉博物馆的2026年周末夜游安排引用官方公告，活动有效期过后不再排入。

## P0 出发检查

- 卡片、详情与时间轴提供高德地点搜索和百度起终点路线链接，无服务端密钥。百度 Web URI 支持公交、步行、驾车；骑行通过高德确认地点后手动选模式及起点。地图耗时不会自动回传，需要用户回填。
- 按出行日期保存准确入口、开放时间、预约状态与入场窗口；关闭或无票不排入。活动季须选择具体武汉场次、地点和固定起止时间，迟到不能排入。未知坐标不编造路程。
- 可选出发地、返程目的地、最晚返回和每段机动时间；首尾交通参与约束。清单区分用户确认与系统估算，换日期、地点或全程交通策略会清理相应旧耗时。
- `departure.js` 处理地图链接与确认数据，`departure-ui.js` 提供核实表单。所有确认仅保存在本机，不代表实时库存、地图接口返回或已完成预约；官方公告与用户保存的预约来源分别显示。

## P0 易用性改进

- “我的计划”先展示全天预算及时间轴草案，出发设置和核实清单可展开。同一站的入口、营业与预约合并为一个任务；交通按当前顺序预填，集中编辑后一次保存。未知数据仍需核实，估算不会自动变成已确认。
- 全天人均预算包含所有想去地点（含待安排地点）、额外餐饮和完整往返交通预留。首次按发现页预算初始化并保存，默认餐饮30元、交通20元只是可修改预留。空值表示未知，0表示明确无此开销。活动内已包含的消费不应再计入额外餐饮。
- 超额时提供精简清单及低价替换预览，由用户应用。费用变低不保证时间可行，替换后会重新排程。调整可以在继续修改或刷新前撤销，移出最后一站仍保留撤销入口。
- 冲突说明包括缺失交通、闭馆、预约入场与返回超时。点击“查看可行调整”后，尝试智能排序、提前出发、延后结束或缩短本站停留；每个建议均完整重算，保证包含目标站且不丢失原已排入站点。固定场次不能缩短。单项时间调整最多尝试4小时，不承诺找到所有可行解。
- `planning-assistant.js` 为预算与方案校验纯函数；`planning-assistant-ui.js` 提供预算、方案预览、撤销与批量交通界面。费用是估算与预留，不是地图或票务报价。

验证：`node --test tests/*.test.cjs`。浏览器检查包括营业时间错误、确认后排入、逐段交通与耗时更新、刷新持久化、手机时间轴排版。

# 周末出逃 · 城市探索指南

公开访问：https://huster-zc.github.io/meituan/

面向大学生的周末探索产品原型。原生 HTML/CSS/JavaScript，无构建和服务端依赖，保持 GitHub Pages 域名不变。

## 产品流程
- 发现：人均预算、晴雨天气、同行人数硬筛选；兴趣优先排序；搜索、分类、收藏和价格/时长排序。
- 计划：加入/移除活动、汇总预算和时长、创建小队、生成可跨浏览器打开的邀请链接。
- 手账：打卡、实际花费、体验攻略、生成可公开打开的攻略链接。
- 手机和桌面自适应；弹窗支持 Escape、键盘焦点与原生表单校验。

## 明确边界
武汉 6 个活动是示例提案，天气为可切换的演示数据，不是实时预报或真实演出库存。图片来自 Unsplash，均为氛围配图。价格为原型估算，不含交通。所有个人数据仅保存在当前浏览器 localStorage；没有账户或实时组队报名。分享链接包含用户主动分享的文字，接收者可读取，勿填入隐私信息。

## 本地运行与发布
在仓库根目录执行 `python -m http.server 4173`，访问 http://localhost:4173 。直接发布 main 分支根目录到 GitHub Pages，入口 index.html，资源使用相对路径，路由使用 hash。后续 push main 持续更新同一公开链接。

## 验收
检查零预算和雨天筛选、兴趣排序、空结果重置、收藏、计划持久化、小队邀请跨页面读取、手账分享、恶意 HTML 转义、375px 手机布局、图片加载和线上 HTTP 200。

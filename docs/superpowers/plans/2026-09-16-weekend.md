# 周末出逃实现与验收计划

## 设计
保持现有 GitHub Pages 静态部署。发现周末、我的计划、探索手账三个 hash 视图。森林绿、暖白和陶土橙；活动照片突出，筛选和费用可直接比较。桌面左侧偏好，右侧三列卡片；手机偏好折为两列、活动两列。原型数据与本机存储明确披露。

## 实现
1. index.html：语义化导航、主内容区、页脚和共享 dialog。
2. styles.css：响应式页面、卡片、计划、手账、模态表单及焦点状态。
3. app.js：示例数据、硬约束筛选和兴趣排序、localStorage、计划和收藏、组队、打卡、hash 分享链接，所有用户内容 HTML 转义。
4. README：产品边界与同域名更新方式。

## 验收与部署
JavaScript 语法检查；浏览器桌面/手机布局；筛选、空状态、收藏、持久化、邀请和攻略分享完整流程；核实公开网站返回最新内容。Git 提交并推送原仓库 main，保持 https://huster-zc.github.io/meituan/ 不变。

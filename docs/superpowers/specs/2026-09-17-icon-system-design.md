# 周末出逃全站图标系统设计

## 目标

统一全站图标的视觉语言，替换 emoji、字体符号和不一致的字符图标，让图标与现有墨绿、米白、自然编辑风界面协调。改动只涉及图标表达和必要的可访问性标记，不改变现有页面结构、功能和文案含义。

## 视觉语言

- 使用项目内置的内联 SVG，不加载字体图标或第三方 CDN。
- 所有图标使用 `24 × 24` 的 `viewBox`，默认 `fill="none"`、`stroke="currentColor"`。
- 主线宽统一为 `1.8`，使用圆角端点和圆角连接；收藏状态可使用实心心形表达已收藏。
- 普通按钮图标显示为 `16–18px`，独立圆形按钮显示为 `20–22px`，品牌标志保持当前视觉面积。
- 图标颜色继承所在控件文字颜色；天气图标可使用现有暖橙色点缀。
- 动效仅使用颜色、背景和透明度变化，时长为 `150–220ms`；遵守现有的 `prefers-reduced-motion` 规则。

## 图标清单与替换规则

| 场景 | 当前表达 | 新图标 | 行为 |
| --- | --- | --- | --- |
| 品牌标志 | `↗` 字符 | 圆角东北箭头 | 保留现有绿色方形容器 |
| 天气 | `☁`、`☂`、`◷` | 晴、少云、多云、雾、雨、雪、雷暴 SVG | 根据 Open-Meteo 天气码动态切换 |
| 收藏 | `♡`、`♥` | 线性 / 实心心形 | 保留 `aria-pressed` 和收藏文案 |
| 时间 | `◷` | 圆形时钟 | 用于活动时长和营业时间 |
| 搜索 | `⌕` | 放大镜 | 标记为装饰性图标 |
| 关闭 | `×` | SVG 关闭 | 保留“关闭弹窗”无障碍名称 |
| 成功 | `✓` | 圆形勾选或勾选 | 已加入、保存完成等状态 |
| 添加 | `+` | 加号 | 记录和加入操作；不重复朗读 |
| 外链 / 前进 | `↗`、`→` | 外链或东北箭头 | 外链与页面内行动分别使用对应图标 |
| 排序 / 移动 | `↓`、`↑` | 下箭头、上箭头 | 保留按钮的完整 `aria-label` |
| 路线 | `↳` | 转向箭头 | 用于转场说明 |
| 灵感装饰 | `✧`、`✺` | 闪光、罗盘或叶片 | 仅作装饰，不进入读屏文本 |

活动数据中的路线文案所含 `→` 是文本内容，用作步骤分隔，不作为交互图标处理。

## 实现结构

在独立的 `icons.js` 中提供 `icon(name, options)`，返回受控的 SVG 字符串。图标名称只接受预定义映射，尺寸和 CSS 类经过白名单处理，避免把业务内容插入 SVG。该文件在 `app.js` 与 `planner-ui.js` 之前加载。

天气模块新增“天气码到图标名”的纯函数，保持现有天气文案与数据请求不变。页面渲染函数通过 `icon()` 输出图标，并为装饰性图标设置 `aria-hidden="true"`。只有纯图标按钮依靠按钮本身的 `aria-label` 提供含义。

CSS 增加统一的 `.icon`、`.icon-button` 和尺寸修饰规则。圆形图标按钮的点击区域桌面端至少 `40 × 40px`，移动端至少 `44 × 44px`；收藏、关闭等现有按钮同步扩大可点击区域，但不改变卡片和弹窗布局。

浏览器可能覆盖在图片上的“识图”按钮不属于站点 DOM，不纳入实现，也不尝试遮挡或禁用。

## 验收标准

- 页面 UI 中不再使用 emoji 或 `♡ ♥ ☁ ☂ ◷ ✧ ✺ ⌕ × ✓ ↑ ↓ ↗` 等字符充当图标。
- 发现页、活动卡片、天气卡片、详情弹窗、空状态、手账、分享页和行程规划页均完成检查。
- 天气码的晴、云、雾、雨、雪、雷暴均能得到对应 SVG，未知状态使用中性天气图标。
- 收藏、关闭、移动、搜索和外链操作保留清晰的可访问名称、键盘焦点和状态表达。
- 在 375px、768px、1024px 和 1440px 宽度下，图标不挤压文字、不越界，也不导致布局跳动。
- 现有业务测试继续通过，并新增图标映射、天气图标映射及页面字符扫描测试。

## 范围边界

本次不更换字体、配色、照片、页面信息架构或浏览器自身覆盖控件。不会引入外部图标 CDN、SVG 网络请求或新的运行时依赖。
